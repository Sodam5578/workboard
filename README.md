# 📋 업무 관리 시스템 (Workboard)

개인 및 소규모 업무를 직관적이고 체계적으로 관리할 수 있는 단독 실행형 경량 웹 애플리케이션입니다.

## ✨ 주요 기능
- **업무 및 일정 통합 관리**: 단일 업무, 단계별 업무(하위 체크리스트), 일정/회의 등록
- **스마트 뷰**: 오늘 할 일, 예정(30일), 중요 업무, 분류별 목록, 캘린더(월간/주간) 뷰 제공
- **반복 업무 지원**: 매일, 매주(특정 요일), 매월 등 유연한 반복 주기 설정
- **기기 및 환경 최적화**: 
  - 반응형 디자인 (데스크톱, 태블릿, 모바일 지원)
  - 다크 모드 / 라이트 모드 / 글자 크기 조절
  - 멀티태스킹용 미니창(위젯 뷰) 지원
- **데이터 안전성 및 백업**:
  - 브라우저 로컬 저장소(Local Storage) 저장 (외부 서버 전송 없음)
  - JSON 전체 백업 및 복원 기능
  - CSV 및 ICS(캘린더) 내보내기 지원

## 🚀 배포 및 사용 안내
이 프로젝트는 순수 HTML/CSS/JavaScript로 구성되어 있어 **GitHub Pages**나 정적 웹 호스팅을 통해 어디서든 바로 접속하여 사용할 수 있습니다.

> **참고**: 데이터는 접속 중인 브라우저의 로컬 저장소에 저장되므로, 기기 변경 시에는 `설정 > JSON 백업` 기능을 활용해 데이터를 백업/복원해 주세요.
